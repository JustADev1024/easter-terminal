# Easter Terminal

A simple terminal program with hidden Easter eggs.  
Type commands and discover surprises.  
(More Easter eggs may appear in the future, but no promises.)

## How to run

```bash
git clone https://github.com/yourusername/easter-terminal.git
cd easter-terminal
clang++ src/main.cpp -o easter-terminal
./easter-terminal
```

## Commands

| Command | Response |
|---------|----------|
| `F` | Press F to pay respects. |
| `exit` | Goodbye! |
| `anything else` | IDK what you want to say me... |
